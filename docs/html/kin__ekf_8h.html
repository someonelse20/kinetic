Perform the EKF update step using prediction + measurement correction.

Implements the extended Kalman filter update cycle:

  1. Covariance prediction: P = F * P * F^T + Q
  2. Kalman gain: K = P * H^T * (H * P * H^T + R)^-1
  3. State update: X = X + K * (Z - H * X)
  4. Covariance update: P = (I - K * H) * P

The state prediction (X^) and state transition Jacobian (F) are provided as arguments since different EKF implementations compute them differently.
