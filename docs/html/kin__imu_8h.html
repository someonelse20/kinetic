Detailed Description

Kinetic IMU Sensor Fusion Library.

This library provides an Extended Kalman Filter (EKF) implementation for IMU data processing. It fuses accelerometer, gyroscope, and magnetometer measurements to estimate orientation (roll, pitch, yaw).

Initialize IMU EKF from accelerometer and magnetometer readings.

Computes initial orientation using accelerometer/magnetometer fusion, initializes reference frames (g_ref, m_ref) based on magnetic dip angle, and sets up noise covariance matrices.

Parameters
imuPointer to imu_t structure to initialize (must be allocated)
accel3-element gravity vector [ax, ay, az]
mag3-element magnetic field vector [mx, my, mz]
Returns
EKF state quaternion, or NULL on failure
