{\bfseries{EKF math}}: Based on AHRS EKF documentation (\href{https://ahrs.readthedocs.io/en/latest/filters/ekf.html}{\texttt{https:\+/\+/\+ahrs.\+readthedocs.\+io/\+en/\+latest/\+filters/\+ekf.\+html}})

{\bfseries{Coordinate system}}:
\begin{DoxyItemize}
\item Quaternion format: x y z w (little-\/endian convention)
\item Reference frames: NED (North-\/\+East-\/\+Down)
\end{DoxyItemize}

{\bfseries{Reference frames}}:
\begin{DoxyItemize}
\item {\ttfamily accel\+\_\+ref}: Always \+[0, 0, 1] (gravity in NED)
\item {\ttfamily mag\+\_\+ref}: Depends on magnetic dip angle, computed as {\ttfamily \+[cos(dip), 0, sin(dip)]}
\item {\ttfamily g\+\_\+ref}: Always \+[0, 0, 1] (gravity direction, stored in imu\+\_\+t)
\item {\ttfamily m\+\_\+ref}: Normalized magnetic reference, computed as {\ttfamily m\+\_\+ref\+\_\+a / sqrt(cos²(dip) + sin²(dip))}
\end{DoxyItemize}

{\bfseries{Measurement model}}:
\begin{DoxyItemize}
\item Accelerometer reading: {\ttfamily rot\+\_\+matrix\+\_\+trans \texorpdfstring{$\ast$}{*} g\+\_\+ref}
\item Magnetometer reading: {\ttfamily rot\+\_\+matrix\+\_\+trans \texorpdfstring{$\ast$}{*} m\+\_\+ref}
\end{DoxyItemize}\hypertarget{md_AGENTS_autotoc_md4}{}\doxysection{\texorpdfstring{Testing}{Testing}}\label{md_AGENTS_autotoc_md4}
Two primary test modes:


\begin{DoxyEnumerate}
\item {\bfseries{Linear interpolation}} ({\ttfamily tests/\+main.\+cpp}, {\ttfamily tests/\+src/\+sim.\+cpp}):
\begin{DoxyItemize}
\item Interpolates between two orientations over time
\item Runs EKF updates on interpolated "{}true"{} orientation
\item Uses zero-\/noise deterministic mode: no noise injected during interpolation
\item Outputs CSV data to {\ttfamily build/\+estm\+\_\+\texorpdfstring{$\ast$}{*}.txt} and {\ttfamily build/\+true\+\_\+\texorpdfstring{$\ast$}{*}.txt}
\end{DoxyItemize}
\item {\bfseries{Debug divergence}} ({\ttfamily tests/\+debug\+\_\+divergence.\+cpp}):
\begin{DoxyItemize}
\item Prints diagnostic info about measurement model
\item Shows reference frame values before/\+after initialization
\item Useful for debugging EKF convergence behavior
\end{DoxyItemize}
\end{DoxyEnumerate}

{\bfseries{Zero-\/noise test mode}}: During linear interpolation, no noise is added to measurements. This tests perfect sensor convergence but doesn\textquotesingle{}t represent real IMU behavior.

{\bfseries{Default test}}: {\ttfamily sim.\+all\+\_\+axis\+\_\+test(100)} runs all-\/axis test with 100 steps.\hypertarget{md_AGENTS_autotoc_md5}{}\doxysection{\texorpdfstring{Key Implementation Details}{Key Implementation Details}}\label{md_AGENTS_autotoc_md5}

{\bfseries{Measurement types}} ({\ttfamily recording\+\_\+type}):
\begin{DoxyItemize}
\item {\ttfamily general\+\_\+wiggle}: General movement/\+shaking test
\item {\ttfamily gyro\+\_\+ref\+\_\+positive\+\_\+x/\+y/\+z}: Gyro reference on each axis (positive rotation)
\item {\ttfamily gyro\+\_\+ref\+\_\+negative\+\_\+x/\+y/\+z}: Gyro reference on each axis (negative rotation)
\item {\ttfamily accel\+\_\+ref\+\_\+positive\+\_\+x/\+y/\+z}: Accel reference on each axis (positive force)
\item {\ttfamily accel\+\_\+ref\+\_\+negative\+\_\+x/\+y/\+z}: Accel reference on each axis (negative force)
\end{DoxyItemize}
